# «Состояние Mac» — установщики

Здесь лежат только готовые установочные образы программы «Состояние Mac» (раздел **Releases**).
Код программы хранится в закрытом хранилище.

Программа сама проверяет этот раздел («Проверить обновления…» в меню программы) и ставит новую версию,
только если она подписана тем же сертификатом, что и установленная.

Установка вручную: скачайте `Sostoyanie-Mac-<версия>.dmg` из последнего выпуска, откройте и перетащите
«Состояние Mac» в папку «Программы». Нужна macOS 13 или новее, процессор Apple или Intel.
