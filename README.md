# MacDozor — установщики

Здесь лежат только готовые установочные образы программы **MacDozor** (раздел **Releases**).
Код программы хранится в закрытом хранилище.

MacDozor — своя программа для Mac вместо CleanMyMac и Memory Clean: следит за памятью, диском, автозапуском,
сбоями, сетью и признаками вредоносного, убирает мусор и дубликаты только в Корзину.

Программа сама проверяет этот раздел («Проверить обновления…» в меню программы) и ставит новую версию,
только если она подписана тем же сертификатом, что и установленная.

**Скачать последнюю версию:** https://github.com/kostan2000-blip/macdozor/releases/latest/download/MacDozor.dmg

Установка вручную: скачайте образ по ссылке выше (или `MacDozor-<версия>.dmg` из нужного выпуска), откройте и перетащите
MacDozor в папку «Программы». Нужна macOS 13 или новее, процессор Apple или Intel.
